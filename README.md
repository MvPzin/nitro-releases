# NITRO

Otimizador de PC para jogos — feito por **MvP**.

## Como instalar
1. Baixe o **NITRO-Setup** mais recente em **[Releases › Latest](https://github.com/MvPzin/nitro-releases/releases/latest)**.
2. Abra o instalador. Se o Windows mostrar *"O Windows protegeu o computador"*, clique em **Mais informações › Executar assim mesmo** (o app não tem assinatura digital paga).
3. Pronto. A partir daí o NITRO **se atualiza sozinho** ao abrir.

## O que tem
- Painel em tempo real (CPU, GPU, RAM, discos, temperaturas)
- Otimizações do Windows reversíveis, uma por uma
- Limpeza de arquivos temporários e caches
- Apps: seus jogos instalados + prioridade alta
- Teste de rede (ping, variação, perda, velocidade e diagnóstico)
- Overlay de FPS/CPU/GPU/RAM durante o jogo (Ctrl + Shift + O)

> Para ver a temperatura do processador, instale o driver gratuito [PawnIO](https://pawnio.eu).
